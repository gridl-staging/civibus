## domains

| File | Summary |
| --- | --- |

| Directory | Summary |
| --- | --- |
| campaign_finance | The campaign_finance domain manages acquisition, parsing, and validation of election contribution data from FEC bulk files, 25+ state jurisdictions, and major cities (LA, NYC, SF), including dark money and independent expenditure tracking. |
| civics | The civics directory is a domain plugin that provides canonical Pydantic models, ingestion helpers, and graph-loading functionality for civic entities such as offices, electoral divisions, contests, and officeholdings. |
| property | The property domain processes Durham ArcGIS parcel records to extract and normalize person and organization entities, then loads property ownership and zoning relationships into the Apache AGE knowledge graph. |
